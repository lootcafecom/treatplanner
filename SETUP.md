# TreatPlanner.com — Setup Guide

## Pages Built
- / → Homepage with hero search + stats + destinations + cost table
- /search → Hospital comparison engine with currency switcher
- /calculator → Total trip cost calculator (all currencies)
- /how-it-works → 6-step process page
- /procedures → All 9 procedure categories
- /hospital/[id] → Hospital detail + doctors + reviews
- /book/[id] → 4-step booking flow with payment
- /dashboard → User bookings + trip manager
- /admin → Admin panel with analytics
- /login → Login + signup
- /about → About page
- /contact → Contact form

## Run Locally
npm run dev → http://localhost:3000

## Deploy to Vercel (Free)
1. Go to vercel.com → Sign up free
2. Click "Add New Project"
3. Upload this folder OR connect GitHub
4. Click Deploy → Done!
